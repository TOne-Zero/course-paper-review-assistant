# 模型接口与输出校验

支持常见Chat Completions、Responses、Anthropic Messages与Gemini请求/响应和流式事件。适配只在同源范围尝试有限路径及明确不支持参数的兼容方式；不把认证、额度或网络错误冒充成功。连接测试只发送小请求，不发论文、不保存草稿配置。

正式评阅按标准逐维请求，容量允许时使用完整可靠原文；超出容量时分批提取证据再综合，不把提取缺口当作已读。显示阶段、活动信号和实际理由草稿，不展示原始reasoning_content；草稿不作为已验证分数。

JSON可移除BOM、完整外围解释和代码围栏，但内部不补字段或伪造分数；拒绝重复字段、多个对象、非法数值、缺失小项、分值越界和无法核对的原文。格式、结构、引用、截断等可恢复错误每类最多恢复一次，每阶段最多两次额外生成，所有实际请求计入调用次数上限。错误或材料不足保留空分，总分不把空分当0。

MODEL_MAX_OUTPUT_TOKENS=0在Chat Completions、Responses和Gemini中省略输出上限参数；服务商仍有自己的限制。Anthropic原生协议要求max_tokens，优先读取其模型元数据；未公布时使用适配器默认值，并仅按服务明确的允许值调整。并非无限输出保证。单次超时、调用次数、输入容量和响应体安全限制仍保留，可在.env.example中查看部署参数。

服务商、模型、套餐与部署网关能力不同。测试连接成功不代表长文或评分质量已通过验证；结构与引用校验也不证明学术判断正确。
