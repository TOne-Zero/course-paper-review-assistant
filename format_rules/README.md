# 格式规范文件说明

本目录目前仅有 `01_demo_structure.json`，是本项目自拟的三条演示规则，不是中国传媒大学或任何学校的官方规范。没有真实学校规范时，不补造字号、页边距、参考文献样式等要求。

## 配置字段

文件须为 UTF-8 JSON，格式版本 `schema_version=1.0`，最大 1 MB。顶部必须有 `id`、`name`、`version`、`source`、`scope`、`is_demo` 和 `rules`。

每条规则必须有：

| 字段 | 含义 |
| --- | --- |
| `id` | 唯一标识，只用字母、数字、下划线和短横线 |
| `name` | 规则名称 |
| `source` | 规范文件名、发布者、具体条款等可核对依据；演示规则须明确自拟 |
| `version` | 本条规则的版本 |
| `scope` | 适用范围说明，供教师核对论文是否适用 |
| `method` | 检查方法；不是可执行代码 |
| `parameters` | 检查方法允许的结构化参数 |
| `requirement` | 本项要求与判定范围 |
| `enabled` | 可选布尔值，默认启用；禁用返回“无法判断/未执行” |

本版本只有 `section_presence` 方法，参数只能是 `{"section":"摘要"}`、`{"section":"关键词"}` 或 `{"section":"参考文献"}`。执行范围固定为全文可用提取文本，排除明显目录与不可靠页面。`scope` 文字不会被当作程序解释；额外的字号、页数、位置等限制不能仅写在说明里就认为已被执行。需要其它检查时应增加明确的方法与测试，本版本不自动替代未知方法。

可复制演示文件建立新配置；获得真实课程规范后，应记录准确来源、版本和具体条款，再由教师确认适用范围。`is_demo=false` 只是配置提供者声明，不代表本应用已认证学校来源。界面可导入配置供当前会话使用，不自动写入规范目录，也不在无效导入时回退到演示规则。

## 判定边界

- **符合**：在可靠页面检出独立节标题/标签和可引用的非空文本。只满足本条“检出”要求，不代表内容质量或全篇格式合格。
- **疑似不符合**：全文可检索、没有已知解析/图像/表格风险，但未找到该标签。结果附已搜索页码，不编造“缺失发生页”，仍需教师查看原 PDF。
- **无法判断**：解析失败、文字不足、扫描/图像风险、表格或版式检测未完成、只有标签而不能确认内容、规则缺失/无效/禁用或方法未实现等。

目录条目、普通正文中提及“摘要/关键词/参考文献”、孤立页码和连续的空标签不作为通过证据。表格页中的标签也不会直接作为章节合格依据。

表格排除使用开源 pdfplumber 的启发式检测，不能识别所有复杂版面；图形对象较多时直接保留不确定性。使用仅 pypdf 的提取路径、未完成版式检测时，也不会将未检出自动判为疑似缺失。

PDF 页数、媒体框宽高和旋转角仅为信息展示，不等同于纸张印刷尺寸、字号、行距或正文页边距。当前没有这些版式属性的合格规则，也没有真实学校规范的符合性认证。

## 教师复核与导出

系统判断、页码证据、规则来源与版本单独记录。教师可在界面填写自己的结论与依据，不覆盖系统判断；复核是本地演示，没有身份认证，只存当前会话。切换论文或规范会清除旧结果；需要留存时下载格式检查与复核 JSON。格式检查不输出总分，不向课程评分自动扣分。
